| Instruments                                                                                                                                  | Unit                          | Notes                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | -------------------------------------------------------------------------------------------- |
| `obc-compass`, `obc-heading`, `obc-compass-sector`                                                                                           | Degrees                       | The list is `headingAdvices`; the shared `advices` is the same list                          |
| `obc-rudder`                                                                                                                                 | Degrees                       |                                                                                              |
| `obc-wind-propulsion`                                                                                                                        | Degrees                       | The list is `sailAngleAdvices`; the shared `advices` is the same list                        |
| `obc-speed-gauge`                                                                                                                            | The gauge's speed unit        | `speedAdvices` is a deprecated alias                                                         |
| `obc-instrument-radial`, `obc-gauge-radial`, `obc-rot-sector`, `obc-gauge-proportional`, `obc-gauge-generator`, `obc-gauge-motors-and-pumps` | The gauge's value             |                                                                                              |
| `obc-azimuth-thruster`                                                                                                                       | Degrees and percent of thrust | Two lists, `angleAdvices` and `thrustAdvices`, sharing one trigger and emphasis              |
| `obc-thruster`, `obc-main-engine`                                                                                                            | Percent of thrust             | A band across zero is split at zero; `thrustAdvices` on the engine is a deprecated alias     |
| `obc-bar-vertical`, `obc-bar-horizontal`                                                                                                     | The scale's value             | `advicePosition` places the band: `inner` (the default), `outer` or `center`                 |
| `obc-gauge-vertical`, `obc-gauge-horizontal`                                                                                                 | The scale's value             |                                                                                              |
| `obc-gauge-trend`, `obc-automation-tank`, `obc-depth`                                                                                        | The scale's value             | `advice` is a deprecated alias; `hasAdvice`, off by default, switches the bands and areas on |
| `obc-depth-actual`                                                                                                                           | Depth units                   | `advice` is a deprecated alias; triggered by `depth`                                         |
| `obc-draft-trim`, `obc-heave`                                                                                                                | The scale's value             | `advice` is a deprecated alias; triggered by the trend band, not by the current reading      |
| `obc-pitch-roll-heave`                                                                                                                       | Metres                        | `heaveAdvice` is the heave column's list                                                     |
| `obc-line-graph`, `obc-area-graph`                                                                                                           | The y axis                    | Areas only, see [Areas on a chart](#areas-on-a-chart)                                        |
| `obc-watch`                                                                                                                                  | Degrees                       | Draws the list as given; the instrument around it resolves the states                        |
