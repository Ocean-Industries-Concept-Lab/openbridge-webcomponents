| State       | Looks like                                            | Meaning                                                      |
| ----------- | ----------------------------------------------------- | ------------------------------------------------------------ |
| `hinted`    | Light grey outline, stripes or fill                   | Present, but not where the operator should look              |
| `enabled`   | Darker grey outline, stripes or fill                  | Visible; the default when an entry gives no state            |
| `active`    | The category's tint and outline                       | The band the operator is guided towards                      |
| `triggered` | The category's full colour; boundary ticks go primary | A reading is inside the band; the instrument sets this state |
